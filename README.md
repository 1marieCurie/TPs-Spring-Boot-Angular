## A propos
TPs Spring Boot-Angular est un dossier qui contient tout les travaux pratiques qui visent le developpement et l'architecture des projets constructifs en framework Spring Boot en parallèle d'un frontend basé sur Angular

- Pharmacy project : projet de gestion des médicaments d'une pharmacie en visant la sécurité de site en premier lieu
- TODO : un projet importé et amélioré accompagné d'un rapport détaillé des étapes suivies
- Site web Avito : une application qui simule l'idée de site web marocain Avito.
